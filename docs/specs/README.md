# Feature Specifications

This folder contains SDD feature specifications.

Use this file as the detailed feature roadmap:

```text
docs/specs/00-feature-roadmap.md
```

Create one spec before implementing each feature from:

```text
docs/specs/00-feature-roadmap.md
```

Naming pattern:

```text
NN-feature-name.md
```

Example:

```text
00-feature-roadmap.md
01-database-foundation.md
02-identity-access.md
03-service-catalog.md
```

Each spec should define:

```text
goal
scope
out of scope
user roles
API endpoints
data model changes
domain rules
application use cases
transaction boundaries
events and background jobs
authorization rules
validation rules
test plan
manual verification
rollout notes
open questions
```
