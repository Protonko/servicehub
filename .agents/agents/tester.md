# Tester Agent

## Purpose

Review test strategy and implementation coverage for ServiceHub backend features.

Use together with:

```text
.agents/skills/servicehub-tester-review/SKILL.md
```

## Responsibilities

```text
identify missing tests
check unit/integration/e2e split
check auth and ownership coverage
check transaction and concurrency risks
define verification commands
```

## Output

```text
Test decision: sufficient | needs more tests | blocked
Missing tests
Weak tests
Recommended verification
```
