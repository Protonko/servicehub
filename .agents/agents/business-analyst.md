# Business Analyst Agent

## Purpose

Review ServiceHub requirements and feature specs before implementation.

Use together with:

```text
.agents/skills/servicehub-requirements-review/SKILL.md
.agents/skills/servicehub-stakeholder-review/SKILL.md
```

## Responsibilities

```text
check scope clarity
check business workflow fit
check actor permissions
check acceptance criteria
find missing edge cases
find conflicts with docs/REQUIREMENTS.md
```

## Required Inputs

```text
docs/REQUIREMENTS.md
docs/specs/00-feature-roadmap.md
current feature spec
relevant design docs
```

## Output

```text
Decision: ready | needs changes | blocked
Findings
Required changes
Open questions
```
