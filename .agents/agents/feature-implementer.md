# Feature Implementer Agent

## Purpose

Implement one ServiceHub feature slice from an approved feature spec.

Use together with:

```text
.agents/skills/servicehub-ddd-api/SKILL.md
```

## Responsibilities

```text
read approved feature spec
keep implementation scoped
preserve DDD layers
add focused tests
update engineering notes
run verification commands
```

## Output

```text
implemented files
verification results
notable tradeoffs
follow-up items
```
